# 🚗 Gerenciador de Manutenção Preventiva de Veículos

Projeto desenvolvido para a disciplina de **APS — Ciência da Computação**.
O objetivo é desenvolver um sistema para **gerenciar veículos e suas manutenções preventivas**, permitindo cadastrar veículos, registrar manutenções e acompanhar seus históricos.

## 🎯 Objetivo do projeto
Criar uma aplicação em **Java** com **MySQL**, utilizando **POO, MVC e DAO**, com uma interface gráfica para facilitar o gerenciamento das manutenções dos veículos.

## 🛠️ Tecnologias
* Java
* MySQL
* JDBC
* MVC
* DAO
* POO
* Git e GitHub
